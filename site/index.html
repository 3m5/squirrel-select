CSS for the native <select>

Keep the select. Change the look.

Add one class to a native <select> and it takes your colors, corners and spacing. Keyboard, screen readers, autofill and form validation stay with the browser.

  • 0 kB JavaScript
  • Under 3 kB CSS, gzipped
  • 0 dependencies
  • 3 engines tested on every change
Install with
npm 
npm install @3m5-de/squirrel-select
CDN 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@3m5-de/squirrel-select@1/dist/squirrel-select.css">

No rebuild

Why rebuild what the browser already does?

SquirrelSelect styles the select and leaves everything else to the browser.

Our test run checks keyboard use, form behavior and the phone path on every change. How we test

Browser support

Styled as far as each browser allows

The field follows your design in every current browser. How far the open list goes depends on the browser.

  • Fully styled Your browser

    Field and open list, with checkmark, groups and dark mode.

    Chrome and Edge 135+, Safari 27+, with a mouse or trackpad

  • Field styled Your browser

    Your field; the system draws the open list.

    Firefox on the desktop, older Chrome, Edge and Safari

  • Native picker Your browser

    Your field; choosing opens the iOS or Android picker, on purpose.

    Phones and tablets without a mouse or trackpad

Get started

Works with your stack

If your template can write <select class="sqs">, it works. Each guide shows where the stylesheet goes, the markup, and what to watch out for.

  • Plain HTML <link rel="stylesheet">
  • React and Next.js className="sqs"
  • Vue and Nuxt v-model
  • Svelte and SvelteKit bind:value
  • Angular formControlName
  • TYPO3 Fluid f:form.select
  • Symfony and Twig attr: {class: 'sqs'}
  • Laravel Blade @error

For production, pin the exact version or host the file yourself. See Plain HTML.
